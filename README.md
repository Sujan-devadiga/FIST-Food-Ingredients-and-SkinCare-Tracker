# FITS - Fit Food Ingredients Tracking System

FITS is a Python-based application that helps users screen food and skincare ingredients using a reference database.

## Features
- Ingredient analysis
- Image-based ingredient text extraction using OCR
- Ingredient status classification
- Ingredient information and guidance
- CSV export of analysis results

## Tech Stack
- Python
- Streamlit
- Pandas
- Tesseract OCR

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
